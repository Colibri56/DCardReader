## האונבורדינג - 4 שאלות, אחת בכל פעם

בפעם הראשונה שתבקש/י נוהל, הסקיל קודם **קורא בשקט** את `context/` ו-`purpose.md`
שלך (אם קיימים) ומריץ זיהוי-מחברים, כדי לא לשאול מה שכבר ידוע. ואז שואל ארבע
שאלות חמות, אחת בכל פעם, ומשקף בחזרה אחרי כל תשובה:

1. **באיזה תחום העסק, ולמי הנהלים מיועדים?** (עובד/ת חדש/ה? מחליף/ה?) - קובע את
   הטון ואת רמת-הפירוט.
2. **מאיפה הכי נוח שאקרא תהליך שכבר קרה?** - Gmail? וואטסאפ? תמלול? או קובץ
   שתפיל/י בתיקייה? זה לב ה-AUTO-PULL.
3. **לאן הנוהל המוכן נשמר?** - תיקייה במחשב? Google Docs? Notion? מייל? טלגרם?
   ברירת המחדל הבטוחה: קובץ מקומי.
4. **להפוך נהלים למשימות-onboarding?** (אופציונלי) - Monday / Trello / Asana /
   ClickUp, או שמספיק שהצ'קליסט יישב בתוך הנוהל.

בסוף נכתב `config.json`, ומקבל/ת סיכום של משפט. **לא שואלים את ארבע השאלות שוב.**
הפירוט המלא של הזרימה ב-`references/onboarding.md`.

כך שהנוהל פונה לכל עובד/ת.

## כוונון אחרי האונבורדינג

רוצה לשנות משהו? אפשר תמיד לבקש "תעדכן/י לי את ההגדרות של מתעד-התהליכים", או לערוך
ישירות את `config.json` (המבנה שלו ב-`config.example.json`). שדות עיקריים:

| שדה | מה הוא קובע | אפשרויות |
|---|---|---|
| `output.primary` | לאן הנוהל המוגמר נשמר | `local_file` / `google_sheets` / `gmail` / `telegram` / `notion` / `google_docs` / `google_drive` |
| `output.local_dir` | תיקיית-הנהלים המקומית | כל נתיב; ברירת מחדל `outputs/procedures` |
| `source.preferred` | מאיפה מסיקים תהליכים | `gmail` / `whatsapp` / `google_drive` / `local` |
| `tasks.board` | לוח משימות-onboarding | `none` / `monday` / `trello` / `asana` / `clickup` |
| `scan.source_dir` | תיקייה לסריקת תהליכים-חוזרים | כל נתיב; ריק = הסקיל ינסה תיקיות נפוצות |
| `scan.min_count` | כמה חזרות עד שמציעים נוהל | מספר; ברירת מחדל 3 |
| `tz_offset_hours` | אזור-זמן לחותמות-זמן | מספר; ברירת מחדל 3 (שעון ישראל) |

> כל מה שמעבר ל-`local_file` הוא אופציונלי. אם בחרת Notion/Docs/לוח אבל הם לא
> מחוברים כרגע - הסקיל לא נשבר: הוא שומר עותק מקומי (וגם Sheets אם זמין) ומסביר לך
> בדיוק מה קרה ואיך להעביר ליעד שבחרת כשתחבר/י.

## להוסיף מחבר אופציונלי

1. העתק/י את `.env.example` ל-`.env` בתוך תיקיית הסקיל.
2. מלא/י רק את המפתחות של המחבר שאת/ה רוצה (למשל `TELEGRAM_BOT_TOKEN`).
3. ה-`.env` האמיתי לא נכנס ל-git ונשאר אצלך במחשב.

כלי Google (Gmail / Docs / Sheets / Drive) מגיעים בדרך כלל דרך החיבור שכבר קיים
בסשן Claude Code שלך (MCP או OAuth), ולכן בדרך כלל לא צריך מפתח עבורם ב-`.env`.
