# SOP Builder - מתעד התהליכים

סקיל שמוציא את העסק מהראש שלך. הוא הופך תהליך חוזר שרק את/ה יודע/ת לבצע - לנוהל
(SOP) נקי, ממוספר ומוכן-להעברה, כדי שעובד/ת או מחליף/ה יוכלו לבצע אותו בלעדיך.

השדרוג שמייחד אותו: **הוא לא מראיין אותך מאפס.** הוא קורא תהליך שכבר ביצעת בפועל -
שרשור-מייל, צ'אט-וואטסאפ, תמלול-פגישה - ומסיק ממנו את השלבים האמיתיים. וההברקה:
הוא גם **תופס לבד תהליכים-חוזרים** ("זיהיתי שחזרת על אותו סוג שרשור 3 פעמים החודש -
לתעד לנוהל?"), כך שהוא מנוע-היצע, לא כלי שמחכה שתיזכר/י.

---

## מה הוא מייצר

מסמך-נוהל נקי ומעוצב, שכולל:
- **מטרה** - למה התהליך קיים
- **מתי מפעילים** - הטריגר
- **שלבים ממוספרים** - מוסקים מהעבודה האמיתית, לא מגרסה אידיאלית
- **אחראי/ת לכל שלב** + **זמן-תקן**
- **מלכודות נפוצות**
- **צ'קליסט סופי** - ובאישורך, גם כמשימות-onboarding לעובד/ת חדש/ה

פלוס: הצעות-תיעוד יזומות כשמזוהה תהליך-חוזר חדש, והצעת-עדכון רבעונית כשהתהליך זז.

---

## הליבה עובדת באפס אינטגרציות

הסקיל בנוי על **הרביעייה האוניברסלית**: קובץ מקומי -> Google Sheets -> Gmail ->
Telegram. את/ה בוחר/ת לאן הנוהל נשמר, והליבה אף פעם לא נשברת. גם בלי שום מחבר -
מצביעים על קובץ-תמלול/שרשור מקומי (או רצים על ראיון קצר), והנוהל המוגמר נכתב
לבחירתך.

מחברים אופציונליים (בחר-פנימה, לא חובה): Gmail / WhatsApp / Drive כמקור-לתהליך;
Notion / Google Docs / Drive כמאגר-נהלים; Monday / Trello / Asana / ClickUp
להפיכת הצ'קליסט למשימות. אין אצל מי שמחבר - נופלים תמיד בחזרה לרביעייה, וזה מסביר
לך מה קרה.

**בלי מפתח-API חובה.** ה"צעד החכם" (קריאת תהליך והסקת שלבים) מתבצע בסשן Claude
Code שלך. המחברים האופציונליים משתמשים בהרשאות שכבר יש לך.

## התקנה ב-60 שניות

1. העתק/י את כל התיקייה `sop-builder/` אל תיקיית הסקילים שלך:
   - ברמת המשתמש: `~/.claude/skills/sop-builder/` (Mac/Linux) או
     `%USERPROFILE%\.claude\skills\sop-builder\` (Windows)
   - או בתוך פרויקט: `<project>/.claude/skills/sop-builder/`
2. בפעם הראשונה שתבקש/י נוהל, הסקיל יעשה **אונבורדינג קצר** (4 שאלות, אחת בכל פעם)
   ויזכור את ההעדפות שלך. הפירוט ב-`ADAPT.md`.
3. מכאן והלאה - בקש/י נוהל בשפה חופשית.

הוראות התקנה מלאות ל-Mac ול-Windows: `INSTALL.md`.

**הדרך הכי קלה - תנו לקלוד להתקין:** הורידו את ה-ZIP של הריפו (Code ← Download ZIP), שימו אותו בתיקיית העבודה שלכם, והדביקו לקלוד קוד:

> תתקין לי את הסקיל מקובץ ה-ZIP של sop-builder שנמצא בתיקייה. אחרי ההתקנה תסביר לי במשפט איך מפעילים אותו.

## מבנה התיקייה

```
sop-builder/
  SKILL.md                  - ה-orchestrator (מנוע, מצבי-הפעלה)        [עברית]
  references/
    onboarding.md           - אונבורדינג, פעם אחת                       [עברית]
    playbook.md             - המנוע המלא, שלב אחר שלב                    [עברית]
    connectors.md           - תפריט מחברים + הפלייסבק לרביעייה           [עברית]
  scripts/
    common.py               - עזרי-בסיס (workspace, config, יעד, זמן)
    build_sop.py            - מרנדר נוהל מ-JSON למסמך נקי + צ'קליסט
    scan_repeats.py         - המנוע הפרואקטיבי (זיהוי תהליך-חוזר)
    detect_connectors.py    - סורק אילו מחברים זמינים (read-only)
    notify.py               - שער-אישור / התראה (Telegram + פלייסבק)
  config.example.json       - מבנה ה-config שהאונבורדינג כותב
  INSTALL.md                - התקנה ל-Mac ול-Windows                    [אנגלית]
  README.md                 - הקובץ הזה                                  [עברית]
  ADAPT.md                  - "להפוך את זה לשלך" + כוונון               [עברית]
  .env.example              - placeholders למחברים אופציונליים בלבד
  .gitignore
```
