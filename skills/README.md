# skills - הסקילים שלך

סקיל הוא מדריך שמלמד את קלוד לעשות משהו בדרך שלך - פעם אחת, ולתמיד.

- סקילים שאתה מוריד מהמועדון: שמור את הקובץ כאן, ואז כתוב לקלוד: "תתקין את הסקיל שנמצא בתיקיית skills". הוא כבר יידע מה לעשות.
- אפשר גם לבקש מקלוד לבנות סקיל חדש: "תבנה לי סקיל שכותב הצעות מחיר בפורמט שלי".

בתוך כל תיקיית סקיל יש קובץ SKILL.md שמסביר לקלוד מה הכלי עושה ואיך להשתמש בו.
